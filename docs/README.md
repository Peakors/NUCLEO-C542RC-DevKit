## 约定

- 界面路径写作 `菜单 > 子菜单 > 按钮`。
- 命令行占位符：`<PROJECT>` 工程名、`<CubeCLT>` 指 `/opt/ST/STM32CubeCLT_1.22.0`。
- 未在本机实测的步骤会标 `> ⚠️ 未实测`，并注明依据来源。
- 截图统一放在 `docs/images/<文档名>/`。
