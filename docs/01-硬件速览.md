# 01 · 硬件速览：NUCLEO-C542RC

> 适用版本：UM3615 Rev 1（2026-02）· 板卡 MB2213-C542RC-B02
> 前置条件：无
> 验证方式：对照板上丝印与 UM3615 第 7 章；本文所有引脚信息均可在 UM3615 找到出处

## 1. 板卡概述

NUCLEO-C542RC 是 ST 的 Nucleo-64 系列开发板，板载 **STM32C542RCT6**：

| 项目 | 参数 |
| --- | --- |
| 内核 | Arm Cortex-M33（含 FPU、DSP 指令） |
| 最高主频 | 144 MHz（593 CoreMark） |
| 封装 | LQFP64 |
| Flash | 256 KB |
| RAM | 64 KB |
| 板载调试器 | STLINK-V3EC（USB Type-C，CN1） |
| 晶振 | HSE 24 MHz、LSE 32.768 kHz |

> Cortex-M33 / 144 MHz 来自 STM32C5 系列页；Flash/RAM/封装来自 UM3615 第 1 章。

## 2. 板载资源

### 2.1 LED（共 5 个）

| 标识 | 颜色 / 用途 | 连接 | 说明 |
| --- | --- | --- | --- |
| **LD1** | 绿色，用户 LED | **PA5**（SB8 短接） | 高电平点亮；由三极管驱动；同时是 Arduino **D13** |
| LD4 | ST-LINK COM | STLINK-V3EC | 串口通信时闪烁 |
| LD5 | 5 V USB | 用户 USB（CN13）供电指示 | — |
| LD6 | ST-LINK PWR | STLINK-V3EC | 调试器供电指示 |
| LD7 | 5 V PWR | 5 V 电源 | 上电即亮 |

### 2.2 按键

| 标识 | 名称 | 连接 | 说明 |
| --- | --- | --- | --- |
| **B1** | 蓝色用户按键 | **PC13** | 外部下拉，**按下为高电平**；建议配置为带消抖的输入 |
| B2 | 黑色复位 | NRST | 复位 MCU |
| B3 | 启动按键 | BOOT0（**PH2**） | 按下时 BOOT0 拉高，从系统存储器（bootloader）启动 |

> ⚠️ UM3615 明确警告：**PC13 不能配置为输出并驱动低电平**，否则按下 B1 会短路。只把它当输入用。

### 2.3 连接器

| 接口 | 标识 | 用途 |
| --- | --- | --- |
| USB Type-C（ST-LINK） | CN1 | 供电 + 调试 + 虚拟串口 + 虚拟 U 盘 |
| USB Type-C（用户） | CN13 | 用户 USB 设备（USB FS） |
| MIPI10 调试口 | CN4 | SWD/JTAG 外接调试 |
| Arduino Uno V3 | CN5 / CN6 / CN8 / CN9 | 兼容 Arduino 扩展板 |
| ST morpho | CN7 / CN10 | 引出全部 MCU 引脚 |
| CAN FD | CN18 | CAN FD 收发（JP9 选择 120 Ω 终端电阻） |

### 2.4 跳线与焊桥（常用）

| 位号 | 作用 |
| --- | --- |
| JP1 | 5 V 电源来源选择 |
| JP5 | IDD 电流测量跳线（测 MCU 功耗时取下并串入电流表） |
| SB12 / SB26 | 默认 ON：USART2（PA2/PA3）连接到 STLINK-V3EC VCP |
| SB46 | 默认 OFF：断开 VCP，改由外部使用 USART2 |
| SB8 | 默认 ON：LD1 连接 PA5 |
| JP3 | STLK_NRST 复位连接 |

> 焊桥改动前请先看原理图 `mb2213-c542rc-b02-schematic.pdf`，改完在文档里记录。

## 3. 时钟与电源

- **HSE**：24 MHz 晶振（板载）。
- **LSE**：32.768 kHz 晶振（板载）。
- **供电**：ST-LINK USB（CN1）、用户 USB（CN13）或外部 5 V；由 JP1 选择 5 V 来源。
- **参考电压**：VREF+ 与 VDDA 默认接 3.3 V；使用 Arduino 扩展板时注意电平为 3.3 V。

> ⚠️ 待核实：外部供电的具体电压范围与最大电流，请查 UM3615 第 6 章表格。

## 4. 虚拟串口（VCP）

| 项目 | 值 |
| --- | --- |
| USART | **USART2** |
| 引脚 | **PA2（TX）/ PA3（RX）** |
| 连接方式 | SB12、SB26 ON，SB46 OFF（出厂默认） |
| 波特率 | 常用 115200 8N1（由固件决定） |
| 设备名（macOS） | `/dev/cu.usbmodem*` |

## 5. 启动模式

| BOOT0 | 启动位置 |
| --- | --- |
| 0（默认，外部下拉） | 用户 Flash（正常运行） |
| 1（按住 B3 复位） | 系统存储器（内置 bootloader，可用于串口/USB 下载） |

## 6. 引脚复用注意

- **PA5 = LD1 兼 Arduino D13**：Zephyr 板级描述中提示 PA5 与 SPI1_SCK 复用，配置 SPI1 时若 LD1 常亮/闪烁异常，先检查 SB8 与引脚分配。
- **PA2/PA3 = USART2 兼 Arduino D0/D1**：外接 Arduino 串口模块时注意与 VCP 冲突，必要时断开 SB12/SB26。
